What it does that a generic notetaker does not

04 / differentiators
01

Keyterm dictionaries

Load technical terms, product names, and names before the call.

02

Code-switching

Mixed-language speech stays in one transcript line.

03

Failures are loud

Join and delivery failures appear with actionable status.

04

Revocable sharing

Signed read-only links revoke individually; plain-text download remains available.

From link to live page

four steps · about forty seconds
01

Sign in

Use a magic link or Google; no install or calendar access.

02

Paste the meeting link

Paste Zoom or Google Meet and optionally select a dictionary.

03

The bot joins

A named participant joins with recording disclosure enabled.

04

The page streams

The call page streams over WebSocket and supports sharing or download.

heritage — the open-source cli

The hosted product grew out of a CLI that puts an AI agent in the call.

The open-source CLI lets coding agents join calls, read transcripts, use chat, and expose presence.

github.com/NikolayS/samograph MIT · Zoom, Meet
$samograph join "https://meet.google.com/..." --dict custom
$samograph watch
$samograph presence thinking "checking rollout metrics"
$samograph chat "plan attached — three retries, same as last week"
$samograph leave
